# 🌐 Vashira Sentinel: Distribution Guide

The Vashira Sentinel is the bridge between the digital wilderness and your sovereign research vault. This guide outlines how to install, use, and distribute the extension.

## 📥 Installation (Local Developer Mode)

To use the Sentinel right now:
1.  Open **Google Chrome** or **Microsoft Edge**.
2.  Navigate to `chrome://extensions/`.
3.  Toggle **Developer Mode** (on the top right) to **ON**.
4.  Click **Load unpacked**.
5.  Select the `sentinel` folder in your project directory: `c:\Users\sdjrp\Documents\inventos\Vashira\vashira-app\sentinel`.

## 🚀 How to Use
1.  Ensure the **Vashira Desktop Application** is running.
2.  Navigate to a research paper on **Google Scholar**, **arXiv**, or **PubMed**.
3.  Click the Vashira Sentinel icon in your browser toolbar.
4.  Verify the metadata and click **MASTER TO HUB**.
5.  The item will immediately appear in your Vashira Research Hub with all metadata and a link to the source.

## 🌍 Public Distribution

To place the extension in the **Chrome Web Store**:
1.  **Zip the contents**: Create a ZIP file of the `sentinel` folder (ensure the `manifest.json` is at the root of the ZIP).
2.  **Developer Dashboard**: Visit the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
3.  **Registration**: Pay a one-time $5 fee to Google.
4.  **Upload**: Upload your ZIP file and provide screenshots and descriptions.
5.  **Icons**: Use the high-fidelity icons located in `sentinel/icons/` (already pre-sized).

## 🛡️ Sovereign Privacy
The Sentinel *never* sends your browsing data to external servers. It only communicates with your **local Vashira Node** on port `51239`.
